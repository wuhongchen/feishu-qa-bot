# Reply Template Guidelines

Use this structure for every intent answer template:

1. Conclusion first: answer the user question in one sentence.
2. Actionable steps: provide 2-4 concrete steps.
3. Next-step guidance: tell user what they can ask next.
4. Optional links: include only highly relevant links.

## Tone

- Friendly and direct
- Avoid over-long paragraphs
- Avoid uncertain words if workflow is known
- Avoid hardcoded dates unless necessary

## Good examples

- "作业截止时间请以群公告最新通知为准。"
- "建议按这个顺序排查：..."
- "如果你把报错贴出来，我可以给你精确修复命令。"
